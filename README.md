# MapTrack · 骑行轨迹地图

将 GPX 轨迹文件映射到高德地图上，生成可交互的本地 HTML 地图页面，并自动在浏览器中打开。

支持读取任意 `.gpx` 户外轨迹文件（骑行、跑步、徒步、自驾等），自动完成 **坐标纠偏、轨迹绘制、运动统计**，输出一张带高德底图、可缩放拖拽、可点击查看坐标的交互地图。

---

## ✨ 功能特性

- **高德地图底图**：默认加载高德路网图，可一键切换「高德 / 高德卫星 / OSM」三种图层
- **坐标自动纠偏**：内置 WGS-84 → GCJ-02 转换，解决 GPX 轨迹在高德地图上的偏移问题
- **轨迹可视化**：红色轨迹线 + 绿色起点 + 红色终点，滚轮缩放、拖拽浏览
- **点击查看坐标**：点击轨迹任意位置，弹出最近轨迹点的 WGS 坐标与海拔
- **运动统计面板**：总距离、累计爬升/下降、骑行用时、平均速度、海拔范围、实时海拔曲线
- **图形化操作**：提供 Tkinter GUI 界面，选择文件 → 一键生成，无需命令行

## 🚀 快速开始

### 方式一：使用 exe（推荐，无需 Python）

1. 把目标 `.gpx` 轨迹文件放到 `dist` 目录（即 exe 旁边）
2. 双击 `骑行轨迹地图.exe`
3. 在窗口中确认轨迹文件（或点「选择 GPX…」挑选任意位置的文件）
4. 点「生成并打开地图」→ 自动生成 HTML 并在浏览器打开

> 已打包的 exe 不依赖 Python 环境，可拷贝到任意 Windows 电脑直接运行。

### 方式二：源码运行（需 Python 3）

1. 在项目根目录放入 `.gpx` 文件（可多个）
2. 双击 `启动轨迹地图.bat`，或运行：
   ```bash
   python gui.py
   ```
3. 也可以命令行直接生成（自动找目录下的 gpx）：
   ```bash
   python generate.py [gpx路径]
   ```

## 🧩 技术要点

### 坐标系纠偏（WGS-84 → GCJ-02）

- GPX 内经纬度基于 **WGS-84**（GPS 国际标准坐标）
- 高德地图在中国使用加密偏移坐标 **GCJ-02**（火星坐标系）
- 若不转换，轨迹会整体偏移数百米。程序内置转换算法，自动将每个轨迹点转换后再绘制，保证与高德道路对齐
- 页面中同时保存两套坐标：GCJ 用于绘制，WGS 用于点击弹窗显示原始坐标

### 地图瓦片

- 使用高德瓦片服务器（`webrd0X.is.autonavi.com`），无 key 直连加载路网图与卫星图
- 该方式适合**个人本地使用**；若用于商用或对外发布，建议改用高德开放平台官方 JS API（申请 key）以规避合规与稳定性风险

### 运动统计计算

- 距离：基于 WGS 坐标的 Haversine 球面距离公式逐段累加
- 爬升/下降：相邻点海拔差分，超过 0.5m 阈值累加
- 用时：取首末轨迹点时间戳差
- 均速：总距离 ÷ 总用时

## 📝 常见问题

| 问题 | 说明 |
|------|------|
| 地图瓦片加载不出来 | 需联网；无 key 直连高德可能被限流，可切换 OSM 图层或换官方 API |
| 轨迹与道路有偏移 | 确认已用最新版本程序，内部会自动做 WGS-84 → GCJ-02 纠偏 |
| 生成失败 / 提示找不到文件 | 确认选择的文件确为 `.gpx`，且包含 `<trkpt>` 轨迹点 |
| 换到没装 Python 的电脑 | 使用 `dist` 里的 exe，无需安装 Python |

---

## 📄 输入格式说明

- **输入**：`.gpx` 文件（GPX 1.0 / 1.1 均可），需包含轨迹点 `<trkpt>`（含 `lat` / `lon`，建议含 `<ele>` 海拔与 `<time>` 时间）
- **输出**：`骑行轨迹地图.html`，直接在浏览器打开查看
